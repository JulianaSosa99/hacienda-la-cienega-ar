# AppHacienda-La-Cienega
Aplicación móvil en Unity con Vuforia y Firebase para una experiencia de Realidad Aumentada gamificada en Hacienda La Ciénega.

## 📅 Planificación del Proyecto

La planificación, seguimiento y control del progreso del proyecto se gestionan en Notion.

Dentro del enlace se encuentran las siguientes secciones:

- **Planificación del Proyecto:** permite visualizar los módulos del sistema, las tareas asociadas a cada módulo, el porcentaje de progreso por módulo y el porcentaje de avance global del proyecto.
- **Cronograma:** permite visualizar en un calendario la distribución y planificación temporal de los módulos del proyecto.
